# Personal Manager 📱

A simple Flutter application for managing and organizing personal projects in one place.

## 📌 About

Personal Manager is a basic project management app designed to help users keep track of their personal projects, organize their work, and manage project-related information.

This project is mainly built as a **Flutter practice project** to improve my skills in mobile application development and UI design.

## ✨ Features

- 📁 Create and manage personal projects
- 📝 Organize project information
- 📋 Keep track of ongoing projects
- 🎨 Simple and clean user interface
- 📱 Responsive mobile layout

## 🛠️ Technologies

- **Flutter**
- **Dart**
